03 · Components

What each piece is responsible for

Client RN + RN Web

One codebase, three targets. Expo Router native; Next.js for marketing. Server state via TanStack Query, UI state via Zustand. Brand tokens pulled from a shared /packages/tokens/ — kit is source of truth.

Triple-Pillar editor is a custom form — three controlled fields plus optional Context attachments, not a rich-text editor.

API Gateway / BFF edge

Hono on Cloudflare Workers or Next.js API routes. Terminates auth, rate-limits (60/min, burst 20), adds request IDs, forwards to services.

Never calls LLM providers directly — always via the LLM Gateway.

Smart Paste stateless

Implements the four-stage Smart Paste flow from the infographic. Text/PDF/URL extraction → Intent Classifier (LLM, JSON-mode) → PII Sanity Check (Strict/Standard) → Pillar Mapping JSON. Persistence via Vault if user explicitly saves.

Architect / Triple-Pillar

Owns Prompt Draft lifecycle. Validates 3-pillar completeness, runs Test Flight via the Gateway, scores risk (V2), produces export bundles.

empty → drafting → ready → flight_pending → flight_done → exported

Vault

CRUD over My Good Stuff (private), Community Recipes (public, moderated), Favourites, Tags. Full-text + vector search via pgvector.

Identity external

Clerk or Auth0. Mobile + web sessions are painful to roll ourselves; social sign-in is table stakes; identity outsourcing frees us to focus on the BYOK key vault.

05 · LLM Gateway · The Load-Bearing Piece

One gateway. One adapter layer.

All three internal services reach providers through this. Adding a fourth provider is one adapter, not a re-plumb. Provider quirks (system messages, JSON mode, image inputs) live inside the adapter — never leaked.

Why a gateway

One place for: PII redaction before egress · token cost attribution per user · per-user quotas · response caching for deterministic Test Flights · failover across providers.

Adapter contract

Every adapter implements complete(), stream(), embed(), returns a normalised {tokens_in, tokens_out, finish_reason, content, raw}.

Default routing (when user hasn't pinned a model)

JobDefault modelWhy
Intent classification (Smart Paste)Gemini Flash or Claude HaikuCheap, fast, JSON mode reliable.
EmbeddingsOpenAI text-embedding-3-smallCheapest 1536d for the use case.
Test FlightUser's selected model (Settings 4.0)We're a multi-LLM tool — never silently swap on the user.
Risk Score V2Same provider as Test Flight, smaller siblingAvoid confirmation bias from same model size.

07 · Security & PII

The pasted content is the threat surface

Users will paste emails, contracts, drafts of personal letters. Treat the inbound content as a hot path.

PII rules

Outbound: Sanity Check runs before every LLM call. Strict mode default for free tier; Standard opt-in per draft.

Storage: flight_runs.output_text column-encrypted at rest. Never key by raw PII.

Logging: structured logs redact known PII patterns. Drop request bodies above DEBUG level.

BYOK

User-supplied API keys: envelope encryption. A per-user data key (KMS-wrapped) wraps the actual provider key. Plaintext exists only inside the LLM Gateway process at call time. Never returned to client.

Auth

IdP-issued JWTs, 15-minute access + refresh. CORS pinned to gotmessy.com + subdomains. CSRF: SameSite=Lax cookies, explicit Origin check on mutations.

Mobile considerations

Triple-Pillar editor must be one-handed. The Drop accepts iOS/Android share-sheet input. Test Flight responses stream — no silent waits on mobile networks. Vault is read-cached for offline browse.

09 · Observability & Cost

Trace one flight end-to-end

Observability

Tracing: OpenTelemetry, propagated client → BFF → service → Gateway. A Test Flight is one trace.

Metrics: per-provider latency, token cost / user / day, Smart Paste pillar-detection success rate, flight failure rate.

Errors: Sentry on client + server. Group by idp_sub — never store emails in error context.

Cost (rough, mid-tier model)

Intent classification500 in / 200 out~$0.0015
Test Flight800 in / 1.2k out~$0.012
Embedding500 in~$0.00001

Free-tier user @ 20 flights/day ≈ $0.30/day. BYOK ≈ zero LLM cost — gateway compute + Postgres rows only. That's why BYOK is Phase 2, not Phase 5.

10 · Open Questions

Decisions deliberately deferred

Flag the trade-off when these surface — don't pick silently.

IdP

Clerk vs Auth0 vs Supabase Auth. Lean Clerk for DX; pricing comparison at scale needed.

Hosting

Cloudflare Workers + Neon, or single Vercel/Railway stack. Workers cheaper at scale, more friction for long jobs.

Mobile distribution

Expo Go → EAS RN. App Store vs PWA-first is a product call.

Moderation

Community Recipes: human review queue vs automated classifier with reports. Probably both, order matters.

Risk Score methodology

Dual-model agreement, search-based fact-check, or human-eval-trained classifier. Different cost shapes.

Subscription tiers

Free / Pro / Team — pricing not set. Impacts BYOK quota design.
